# Лабораторна робота 1 Щоденник тренувань

Консольна програма для варіанта №7 з дисципліни «Програмування мовою Dart». Вона розбирає CSV-подібні записи тренувань, відхиляє пошкоджені рядки, перевіряє дані та формує текстовий звіт.

## Запуск

Потрібен Dart SDK 3.13 або новіший.

```console
dart pub get
dart run
dart format --set-exit-if-changed .
dart analyze
```

## Реалізовані вимоги

- 18 вхідних рядків: 15 правильних і 3 навмисно пошкоджених;
- розбір через `split`, `tryParse` і `DateTime.tryParse`, без `try/catch` для очікуваних помилок;
- валідація дати, тривалості, дистанції, пульсу та самопочуття;
- обробка колекцій конвеєрами `where`, `map` і `fold`;
- групування в `Map<String, List<Training>>` і середні значення для груп;
- сортування за дистанцією або тривалістю з іменованими параметрами;
- звіт через `StringBuffer`;
- замикання-лічильник оброблених рядків;
- регулярний вираз з іменованими групами й маскування через `replaceAllMapped`;
- обчислення давності запису в днях через `DateTime.difference` і `Duration`.

## Структура

```text
bin/lab1_training_diary.dart  # точка входу
lib/training_diary.dart       # розбір, перевірка, агрегації та звіт
```

У `bin/` розташована лише точка входу, а логіка — у `lib/`. Це робить код придатним до повторного використання й майбутнього тестування. Класи в цій лабораторній не використовуються за умовою завдання: запис тренування подано record-типом `Training`.

`List` зберігає порядок записів, а `Map<String, List<Training>>` використано для природного групування за видом активності.

## Залежності

Єдина dev-залежність — `lints`: вона вмикає рекомендовані правила аналізатора Dart. Інших пакетів із pub.dev немає: `DateTime`, `Duration`, `RegExp`, колекції та `StringBuffer` доступні у стандартній бібліотеці `dart:core`.

Пакет `collection` розглядався як альтернатива для допоміжних операцій із колекціями, але не доданий, бо в цій роботі всі потрібні операції є в `dart:core`.
